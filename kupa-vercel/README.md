# קופת הקבוצה: התקנה ב-Vercel

מה בפנים:
- `public/index.html` הדף שהחברים רואים (ושם נכנסים כמנהל)
- `api/` השרת: קריאה לכולם, כתיבה רק עם סיסמת מנהל
- `lib/store.js` לוגיקה משותפת לשרת

## שלב 1. העלאה ל-GitHub
1. פתחו חשבון חינמי ב-github.com והיכנסו.
2. לחצו New repository, תנו שם (למשל `kupa`), בחרו Private ולחצו Create.
3. בדף שנפתח לחצו "uploading an existing file".
4. פתחו את ה-zip ואז גררו פנימה את **כל התוכן**: התיקיות `api`, `lib`, `public` והקבצים `package.json`, `vercel.json`, `.gitignore`.
5. לחצו Commit changes.

## שלב 2. חיבור ל-Vercel
1. היכנסו ל-vercel.com עם חשבון GitHub.
2. Add New, ואז Project, ובחרו את ה-repo. Framework Preset: Other. לחצו Deploy.

## שלב 3. מסד נתונים ואחסון קבלות
בפרויקט, בלשונית **Storage**:
1. Create Database, ובחרו **Upstash Redis** (תוכנית חינמית). חברו לפרויקט.
2. Create, ובחרו **Blob**. כשנשאלים על גישה, בחרו **Public**. חברו לפרויקט.

## שלב 4. סיסמת מנהל
Settings, ואז Environment Variables. הוסיפו:
- Name: `ADMIN_PASSWORD`
- Value: הסיסמה שתבחרו (ארוכה ולא ברורה מאליה)

## שלב 5. פריסה מחדש
Deployments, ואז ... ליד הפריסה האחרונה, ואז **Redeploy**.
(משתני סביבה נכנסים לתוקף רק אחרי פריסה חדשה.)

## שימוש
- פתחו את הכתובת של האתר, גללו לתחתית ולחצו **כניסת מנהל**.
- כל הכנסה, הוצאה וקבלה נשמרות בשרת ומופיעות מיד לכל מי שפותח את הקישור.
- הסיסמה נבדקת בשרת. מי שמוצא את כפתור הכניסה לא יכול לשנות כלום בלעדיה.
- להחלפת סיסמה: שנו את `ADMIN_PASSWORD` ב-Vercel ופרסו מחדש. כל ההתחברויות הקודמות מתבטלות.
